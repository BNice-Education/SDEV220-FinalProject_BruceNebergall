# SkillCraft

## Program Name
SkillCraft — RPG-Inspired Skill Development Tracker

## Description
SkillCraft is a Python desktop application designed to make
personal skill development more engaging through RPG-inspired
progression systems.

Users will be able to create skills, log practice time, earn
experience points (XP), and level up their skills. Skills will
also contribute to character attributes, allowing users to
visualize their overall personal development.

This application is being developed as an individual final
project for SDEV 220 at Ivy Tech Community College.

## Files
Planned project technologies and components:

- Python 3.11 — Primary programming language
- PySide6 — Graphical user interface
- SQLite — Local data storage
- GitHub — Version control
- Trello — Project management

The project structure and file documentation will be
updated as development progresses.

## Considerations
- The application is currently in the planning and early
  development stages.
- Skill progression will use an increasingly demanding
  experience curve.
- Skills may contribute to up to three weighted attributes.
- The initial attribute system will use eight RPG-inspired
  character attributes.
- Features and requirements may change during development.
- The initial release will focus on a single-user,
  offline desktop experience.

## Usage
The application is not yet available for use.

Installation instructions and examples will be added once
